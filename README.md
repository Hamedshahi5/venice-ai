# Venice AI — Intro pages (fa · en · ar · tr · ru)

Independent, **unofficial** intro pages for Venice AI (not affiliated with Venice). Links on the pages are referral links.

🌐 https://hamedshahi5.github.io/venice-ai/ (فارسی) · [/en/](https://hamedshahi5.github.io/venice-ai/en/) · [/ar/](https://hamedshahi5.github.io/venice-ai/ar/) · [/tr/](https://hamedshahi5.github.io/venice-ai/tr/) · [/ru/](https://hamedshahi5.github.io/venice-ai/ru/)

## Rebuild
Texts: `build.py` + `texts_extra.py`. The referral URL is **not stored in the source**; pass it when building:

```
VENICE_REF="<your referral url>" python3 build.py
```

## Counters
Page views, daily unique visitors and referral-link clicks are counted via the free Abacus API (no cookies). View them at `/stats.html` (noindex, not linked). Numbers can include bots, and anyone who reads the page source can see the counter namespace.

## SEO
Per-language pages, unique title/description, `canonical`, `hreflang` + `x-default`, Open Graph/Twitter, JSON-LD (WebPage + FAQPage), `sitemap.xml`.
