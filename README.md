# Venice AI — Intro pages (fa · en · ar · tr · ru)

Independent, **unofficial** intro pages for [Venice AI](https://venice.ai/chat?ref=HqKyx2), encouraging people to try it via a referral link.

## Edit & rebuild
Texts live in `build.py`. After editing run `python3 build.py` — it regenerates every language page and `sitemap.xml`.

## SEO included
Per-language pages with unique title/description, `canonical`, `hreflang` (+ `x-default`), Open Graph / Twitter cards, JSON-LD (WebPage + FAQPage), `sitemap.xml`, fast static HTML.
